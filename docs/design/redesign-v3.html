Hypothesis

Roughly 12K Dominican companies (RNC = ACTIVO) hold government contracts. We want to surface the top recipients by total contract value, broken down by contracting entity and sector.

Source data: rnc_dgii.parquet (DGII export, weekly) and contratos_gov.parquet (gov.do scraper, daily).

[1]
SQL · DuckDB ran 1.2s · 12,456 rows
SELECT r.rnc, r.nombre, SUM(c.monto) AS total
FROM read_parquet('rnc_dgii.parquet') r
JOIN read_parquet('contratos_gov.parquet') c USING (rnc)
WHERE r.estado = 'ACTIVO'
GROUP BY 1, 2 ORDER BY total DESC;

# Load source
df = pl.scan_parquet("rnc_dgii.parquet")

result = df.join(contratos, on="rnc", how="inner")

# Materialize
