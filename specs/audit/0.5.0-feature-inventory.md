# Feature Inventory — pre-0.5.0 audit

Compiled 2026-05-21 from a parallel static audit (4 Explore agents) + user-driven dynamic findings. Goal: zero broken / dead / stub UI before 0.5.0 ships.

**Status legend**: 🟢 works · 🟡 partial (works but has UX bug) · 🔴 broken (dead handler, missing endpoint, or undefined helper)

## Audit method

For each nav tab we checked:
1. Every `@click` / Alpine handler → does the function exist? Is it a stub?
2. Every `hx-get` / `hx-post` → does a route handler exist? Is the response shape what the template expects?
3. JS files for `// TODO`, `// FIXME`, empty function bodies.
4. Buttons / links that look interactive but go nowhere.
5. Dynamic UX behavior (this part is user-driven; the static audit misses it).

The static audit covers (1)–(4). (5) needs a human clicking through.

**Dynamic bug** (user-reported 2026-05-21):

(a navigation list), not an AI prompt input. Users have no way to actually ask the AI from this button. Task #42.

### Explore — 🟢

Static audit: clean. All Alpine handlers defined. Profile data rendering is defensive (null/undefined-safe).

### Data — 🔴

Two real bugs found by static audit:

- 🔴 **Double-click on empty canvas does nothing** despite the UI hint says "Double-click to add a node, or use the toolbar". Root cause: `pipeline.js:699 onCanvasDblClick` does `event.target.closest('[data-node-id]')` first. When canvas is empty, no node elements exist, `nodeEl` is null, the whole handler is wrapped in `if (nodeEl)`. Silent no-op. Task #44.

- 🔴 **`window._applyReproject()` undefined**. Called from `data.html:692` but the function doesn't exist anywhere in the codebase. Likely a leftover from a half-implemented CRS reprojection feature for maps. Either implement or remove the button. Task #45.

### Scheduled — 🟢

Static audit: clean. All Alpine handlers exist, all `/api/scheduler/*` endpoints exist in `routes/scheduler.py`.

### Admin — 🔴 (4+ bugs)

Audit found multiple issues across sub-panels:

- 🔴 **`tuskConfirm()` is undefined**. Called from `admin.html:969` (reset slow queries confirm) and `admin.html:1242` (delete scheduled task confirm). Breaks both flows — user clicks the button and nothing happens. Task #46.

- 🔴 **`tuskPrompt()` is undefined**. Called from `admin.html:979` (PITR base backup label prompt) and `admin.html:1254` (edit Postgres setting value prompt). Breaks PITR base backup creation entirely + setting overrides. Task #46.

- 🟡 **Discrepancy: Admin's Scheduled Tasks panel**. The admin audit agent claims `/api/scheduler/jobs` is missing → panel loads but fetches hang silently. The Scheduled-tab audit agent confirmed the route DOES exist in `routes/scheduler.py:67`. Need verification — run it and check. Task #47.

- All other admin sub-panels (Stats, Active Processes, Lock Monitor, Table Maintenance, Extensions, Database Settings, Roles & Users, Backups, Slow Queries, Indexes, Replication, Server Logs) static-audit clean.

## Cross-cutting gaps

- 🟡 **AI conversation history is stored but not surfaced.** `~/.tusk/ai_memory.db` is populated by every Copilot exchange (`tusk.core.ai_memory`). No UI lists or browses past conversations. Task #43.

Task #51.
